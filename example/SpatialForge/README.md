# SpatialForge Conversation Example

This package keeps the complete compressed DSH conversation and a compact set of assets for continuing it with the current BenchForge workspace.

- Workspace root: the BenchForgeV2 repository root.
- Scene programs: 3 current accepted scenes: office work area, lounge meeting corner, and study pantry corner.
- Collection records: 10 unique records, one per question template, balanced across train/dev/test as 4/3/3. The same records are mirrored in their capture receipts and source files; they are not additional samples.
- Questions: 25 records, split train/dev/test as 10/7/8, covering all 10 templates. Referenced media and annotation assets are retained.
- The full authority answer library and SFT answer records are not included.

See `sample-manifest.json` for the retained record IDs and paths. The original transfer archive, obsolete run snapshots, and unreferenced scratch assets were removed from this public example package.
